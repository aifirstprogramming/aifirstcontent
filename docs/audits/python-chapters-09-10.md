# Python Chapters 9-10 Exercise Audit

The Chapter 9 and 10 manuscripts contain six guided build prompts that belong in
model-free AI First Learn mode.

## Chapter 9

1. `Make a game about a baby duckling who is trying to find its mother using pygame.`
2. `The game currently has no enemies. Add a fox to the game.`
3. `Make two more levels for the game. Each level should get harder with more obstacles and enemies.`

## Chapter 10

1. `Design a level editor for the savetheduckling game.`
2. `Implement undo/redo for the level editor.`
3. `Create a path finding algorithm for the level editor to test if a level is beatable. Make it animated.`

The JSON-saving discussion between the first and second Chapter 10 prompts is
an explanation of the level-editor checkpoint, not another reader exercise.
`save_level_def()` is therefore part of the first exercise's finished project.

The manuscripts also tell the reader to launch the game or editor. Learn mode
represents those actions with **Run program** rather than progress-bearing
exercises: Chapter 9 runs `main.py`, and Chapter 10 runs `level_editor.py`.

The extension prompts at the ends of both chapters intentionally remain outside
model-free Learn mode because the manuscripts direct readers to connect an AI
model before attempting them.
